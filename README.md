# DTF Moldova

Landing page MVP pentru serviciul de print DTF.

- 150 MDL / coală 28 × 50 cm
- cutoff 11:00 (Europe/Chisinau)
- calculator cantitate/preț
- comandă prin WhatsApp

## Local

```bash
npm install
npm run dev
```

## Notă despre fișiere
În MVP, browserul nu poate atașa automat fișierul în WhatsApp. Interfața păstrează numele fișierului în comandă, iar clientul îl atașează în conversația WhatsApp. Pentru upload automat este necesar storage/backend (ex. Vercel Blob).
